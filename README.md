# Mafaza Kuis

Game kuis interaktif untuk siswa: pilih mata pelajaran, jawab soal pilihan ganda A-D,
kumpulkan poin bersama narator dan musik ceria. Guru bisa membuat mapel dan soal
(manual, atau unggah PDF, Word, Excel), serta melihat rekap nilai dan mengunduhnya sebagai PDF.

- `apps-script/` : kode aplikasi (Google Apps Script + Google Sheet) dan petunjuk pemasangan
- `docs/`        : halaman GitHub Pages (pratinjau tautan WhatsApp + tampilan aplikasi)
- `templates/`   : bahan pembuat halaman docs/index.html
